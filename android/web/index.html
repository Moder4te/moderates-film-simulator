받은 사진 — 눌러서 열기

    Sony α7R V 설정 방법
    1. 폰에서 모바일 핫스팟을 켠다(밖에서). 집·스튜디오에선 카메라와 폰을 같은 Wi-Fi에 붙여도 된다.
    2. 카메라 MENU → 네트워크 → Wi-Fi → 액세스 포인트 설정에서 폰 핫스팟(또는 그 Wi-Fi)에 연결한다.
    3. MENU → 네트워크 → 전송/원격 → FTP 전송 기능 → 서버 설정에서 서버 하나를 고르고:
      • 호스트 이름 = 위 서버 주소 (핫스팟이면 「핫스팟」 줄)
      • 보안 프로토콜 = 끔 (이 앱은 평문 FTP만 받는다)
      • 포트 = 위 포트
      • 사용자 정보 = 위 사용자 이름·비밀번호
      • 패시브 모드 항목이 있으면 = 켬
      • 디렉터리 = 아무거나 (폰에는 한 폴더로 모인다)
    4. FTP 기능을 켜고, 찍는 대로 보내려면 자동 FTP 전송을 켠다. 보낼 파일 종류는 RAW+JPEG을 권한다 — RAW만 보내면 장당 수십~백MB라 느리다.
    5. 이 화면에서 FTP 받기 시작을 누른 뒤 카메라에서 연결한다.

    메뉴 이름은 카메라 펌웨어·언어 설정에 따라 조금 다를 수 있다.
